# 🎓 Student Marks Prediction

A simple Machine Learning web application that predicts a student's expected marks based on the number of hours they study.

## 📌 Project Overview

This project uses **Linear Regression** to learn the relationship between study hours and student marks.

The user enters the approximate number of hours studied, and the application predicts the expected marks.

## 🚀 Features

- 🎓 Student marks prediction
- 📚 Study-hours based prediction
- 🤖 Linear Regression machine learning model
- 📊 Training dataset preview
- 📈 Mean Absolute Error (MAE)
- 🌐 Streamlit web interface
- ⚡ Simple and easy-to-use interface

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Linear Regression

## ⚙️ How It Works

1. The dataset containing study hours and marks is loaded.
2. Study hours are used as the input feature.
3. Marks are used as the target variable.
4. The dataset is divided into training and testing data.
5. A Linear Regression model is trained.
6. The user enters the number of study hours.
7. The trained model predicts the expected marks.
8. The predicted marks are displayed on the web interface.

## 🤖 Machine Learning Model

**Algorithm:** Linear Regression

**Input Feature:** Hours of Study

**Target:** Marks

**Evaluation Metric:** Mean Absolute Error (MAE)
